# LGE_EVDD TOML -> STEP CAD 재현 브레인스토밍

## 1. 이번 범위

이번 작업의 목표는 다음 한 줄로 고정한다.

> 하나의 고정 TOML을 입력하면, 선택한 LGE_EVDD 기준 형상과 같은 코어/권선 CAD가 결정적으로 생성되고 하나의 STEP scene으로 저장된다.

포함 범위:

- 코어 형상과 air-gap 형상
- 1차측(TX) 및 2차측(RX) 권선 형상
- 적층 위치, 권선 간격, 리드와 층간 connector
- CAD body 이름, 역할, 재질 이름, bounding box, 부피를 담은 ledger
- STEP export와 STEP 재수입 검증
- 고정 TOML 한 점에 대한 기준 형상 비교

이번 단계에서 제외할 것:

- Maxwell/HFSS 프로젝트 생성
- 재질의 전자기 물성, core-loss curve
- excitation, winding, matrix, boundary, region
- mesh, setup, solve, report, CSV dataset 생성
- AEDT 프로세스 및 라이선스 관리
- 기존 스크립트의 무한 random sampling 및 병렬 실행

즉, production path는 `TOML -> typed spec -> CAD bodies -> STEP + ledger`에서 끝난다.

## 3. 원본에서 보이는 CAD 구조

### 3.1 코어

원본 스크립트의 공통적인 코어 생성 방식은 다음과 같다.

1. 전체 외곽 box를 만든다.
2. 좌/우 window와 중앙 window를 box subtraction으로 판다.
3. `g1`, `g2`, 일부 세대의 `g3`에 해당하는 air gap을 추가 subtraction한다.
4. 중앙 limb 또는 추가 코어 조각을 union한다.

주요 legacy 변수는 `w1`, `l1_leg`, `l1_top`, `l2`, `h1`, `l1_center`,
`l2_tap`, `g1`, `g2`, `g3`, `core_N_w1`, `core_P_w1`이다.

문제는 세대에 따라 `w1` 방향이 바뀌는 등 좌표 관례가 완전히 같지 않다는 점이다.
첫 버전에서는 억지로 공통 축으로 회전시키지 말고, 선택한 gold snapshot의 source-native 좌표계를
그대로 보존하는 편이 안전하다.

### 3.2 1차측 권선

planar 1차측의 공통 패턴:

- 직사각형 spiral centerline을 만든다.
- rectangular cross-section으로 sweep한다.
- 위/아래 두 layer를 서로 mirror하고 Z 방향으로 이격한다.
- 중앙의 수직 connector는 원형 단면 polyline으로 만든다.
- 두 layer와 connector를 하나의 TX body로 union한다.
- 외부 terminal tail은 원본에서 `40 mm` 또는 `80 mm`로 코드에 직접 박혀 있다.

litz 1차측은 실제 strand를 하나씩 모델링하지 않고, 원본 CAD상 원형 단면 하나를 sweep한
등가 bundle body다. 첫 재현은 물리적으로 strand를 세분화하지 않고 이 source-CAD 표현을 따라야 한다.

### 3.3 2차측 권선

2차측은 계열에 따라 planar/plate 표현이 다르지만, 공통적으로 `Rx_1`, `Rx_2` 두 body가
1차측 위/아래에 배치된다. `2series` 계열에서는 두 개의 2차측 경로와 그 적층 위치가 형상 계약의 일부다.

### 3.4 초기 계열 분류

아래 표는 디렉터리명과 representative Python의 CAD method를 바탕으로 한 초기 분류다.
최종 의미는 실제 gold geometry를 열어 확인한 뒤 고정해야 한다.

| 계열 | 초기 해석 | CAD 차이 |
|---|---|---|
| `v1` | 초기 EI 계열 | 단순 core subtraction, planar 1차/2차 |
| `v2` | gap 확장 | `g1`, `g2` 포함 |
| `v3` | legacy 정리판 | `l1_center`, `l2_tap`, 14-turn primary |
| `2series_sec2turn` | 2차측 2-turn/2-series | `Sec_1`, `Sec_2`와 층 배치 |
| `2series_EE_pl_pl` | EE, planar-planar | N/P 코어 확장과 planar 권선 |
| `2series_EI_litz_pl` | EI, litz-planar | 원형 등가 litz TX sweep |
| `2series_EI_litz_plate` | EI, litz-plate | litz TX와 plate RX |
| `2series_EI_pl_pl` | EI, planar-planar | rectangular TX/RX sweep |
| `primary_4turn` | EI planar-planar 파생 | primary turn 수 4 고정 |
| `super` | 여러 세대가 섞인 보관 폴더 가능성 | 파일별 snapshot을 따로 판별해야 함 |

## 5. TOML 계약 제안

### 5.1 fixed와 sweep 분리

첫 단계에서는 range 배열을 넣지 않은 **fixed geometry TOML**부터 만든다.

- fixed TOML: CAD 한 점을 완전히 결정한다.
- sweep TOML: 추후 별도 sampler가 fixed TOML들을 생성한다.

CAD builder 내부에서 random choice를 수행하면 안 된다. sampling이 추가될 때도 유일한 소유자는
공유 sampling API여야 하며 seed를 명시적으로 받아야 한다.

### 5.2 스키마 초안

아래는 구조 제안이지 아직 확정 spec은 아니다. 숫자는 추천 gold AEDT에서 읽은 fixed point를 예로 든다.

```toml

[design]
units = "mm"
family = "two_series_ei_litz_planar"
coordinate_convention = "source_native"
reference_id = "ei_litz_pl_script4"

[core]

l1_leg_mm = 24.1
l1_top_mm = 1.4
l2_mm = 30.9
h1_mm = 1.75
l1_center_mm = 7.0
l2_tap_mm = 0.0
w1_ratio = 1.0
gap_g1_mm = 0.0
gap_g2_mm = 1.25
core_n_extension_mm = 0.0
core_p_extension_mm = 0.0

[primary]
conductor_kind = "litz_equivalent"
turns = 14
width_mm = 1.5
height_mm = 0.175
space_x_mm = 2.6
space_y_mm = 0.6
layer_space_x_mm = 1.1
layer_space_y_mm = 0.2
prepreg_mm = 0.02
layer_count = 2
tail_extension_mm = 40.0

[primary.layer_connector]
cross_section = "circle"
diameter_ratio_to_primary_width = 0.8

[secondary]

turns = 2

width_mm = 7.7
height_mm = 0.105
space_x_mm = 2.8
space_y_mm = 3.3

[cad]
core_material = "ferrite"

secondary_material = "copper"

```

핵심 규칙:

- 모든 CAD 치수는 TOML에 한 번만 존재한다.
- `Tx_width`처럼 이름만으로 의미가 불명확한 legacy 변수는 의미가 확인된 뒤 semantic path로 옮긴다.
- 다른 값으로부터 완전히 유도되는 치수는 TOML에 중복 저장하지 않는다.
- 원본에 hard-code된 tail 길이, connector 지름 비율, 원 단면 분할 수도 숨은 default로 두지 않는다.
- family별로 필요 없는 필드를 `0`이나 빈 문자열로 채우지 않는다. family별 typed spec을 사용하고 잘못된 조합은 즉시 raise한다.
- source 절대경로는 설치 가능한 product spec에 넣지 않는다. `reference_id`와 별도 provenance 문서/fixture로 연결한다.

## 6. 코드 구조 제안

기존 `ssw_step.py`는 2,000줄이 넘고 `coilmaker.py`는 3,000줄이 넘는다. EVDD 형상을 여기에 추가하면
서로 다른 topology의 소유권이 섞인다. 기존 모듈에서는 export/ledger 방식만 참고하고, EVDD는 별도 package로 둔다.

```text
src/peetsfea/evdd/
  __init__.py
  spec.py              # TOML parsing, family별 frozen dataclass, validation
  core.py              # EI/EE core primitive와 boolean
  winding.py           # planar/litz-equivalent/plate centerline와 sweep
  scene.py             # family builder 선택, placement, body registry
  step.py              # STEP + ledger export, re-import validation

src/peetsfea/data/evdd/
  ei_litz_pl_script4_fixed.toml

entry/
  evdd_step.py

tests/evdd/
  test_evdd_spec.py
  test_evdd_core.py
  test_evdd_winding.py
  test_evdd_step.py
  fixtures/
    ei_litz_pl_script4_metrics.json
```

CAD backend은 첫 버전에서 CadQuery 하나로 고정하는 안을 우선 추천한다.

- 현재 SSW STEP path가 이미 CadQuery assembly/export를 사용한다.
- box boolean과 rectangular/circular profile sweep를 모두 표현할 수 있다.
- STEP scene body name과 role은 별도 ledger로 확실히 보존할 수 있다.

기존 PyAEDT 스크립트의 geometry call을 직접 재사용하지 않는다. 원본은 다음 특성 때문에 production code가 아니라
geometry oracle로만 취급해야 한다.

- GUI AEDT 2023.1 직접 실행
- `while True` random sampling
- catch-all exception 후 계속 실행
- retry 및 silent continuation
- Windows 절대경로와 network drive 경로
- 기존 작업 디렉터리 삭제
- solve/report와 CAD 생성의 강한 결합

## 7. 산출물 계약

한 fixed TOML 실행당 아래 파일만 우선 생성한다.

```text
<output_dir>/
  evdd_scene.step
  evdd_step_ledger.json
  evdd_resolved.toml
```

ledger 최소 필드:

- `schema_id`, `spec_version`, `reference_id`
- `source_toml_path`, `scene_step_path`
- `design_id`, `seed`, `units`, `family`
- body별 `name`, `role`, `material`, `model_state`
- body별 `solid_count`, `volume_mm3`
- body별 canonical `bbox_min_xyz`, `bbox_max_xyz`, `bbox_size_xyz`
- 전체 scene bbox
- STEP 재수입 후 body/solid 수

초기 body role 후보:

```text
core
primary_winding
primary_layer_top
primary_layer_bottom
primary_layer_connector
secondary_winding_1
secondary_winding_2
```

STEP에 최종 union body만 넣더라도, builder 내부의 구성 요소와 최종 body 사이의 관계는 ledger에 남긴다.

## 8. 재현 검증 기준

눈으로 비슷해 보이는 것만으로 완료하지 않는다.

### 8.1 parser/contract

- 필수 TOML key 누락 시 즉시 raise
- 잘못된 family/field 조합 즉시 raise
- 음수 두께, 0 turn, window보다 큰 권선 등 기하 불가능 조건 즉시 raise
- 같은 TOML + 같은 package version + 같은 seed에서 같은 `design_id`와 같은 resolved parameter 생성

### 8.2 CAD 자체 검증

- 모든 solid가 valid
- 모든 modeled body의 부피가 0보다 큼
- body 이름이 유일함
- 의도한 union 이후 solid 수가 계약과 일치함
- TX/RX가 코어 window 및 layer placement 조건을 만족함
- gap이 core subtraction에 실제 반영됨
- STEP 파일이 존재하고 크기가 0보다 큼
- STEP 재수입 성공 및 body/solid 수 일치

### 8.3 gold geometry 비교

선택한 AEDT snapshot에서 한 번만 reference STEP 또는 reference metrics를 추출한다.
production generator는 AEDT에 의존하지 않는다.

body별 비교 항목:

- bounding box 6면 좌표
- volume
- center of mass
- body/solid 수
- TX/RX/core 사이 최소 거리
- 가능하면 reference와 generated body의 symmetric-difference volume

권장 초기 tolerance:

- 치수/bbox: `1e-6 mm` 수준부터 시작하되 STEP kernel round-trip 오차를 측정한 뒤 근거 있게 조정
- volume: 절대/상대 tolerance를 함께 사용
- body count와 role/name: exact match

face/edge 개수는 CAD kernel 버전에 따라 흔들릴 수 있으므로 주 acceptance 기준으로 삼지 않는다.

## 9. 구현 순서

### Phase 0 — reference freeze

1. gold `.aedt` 또는 representative `.py` 하나를 고른다.
2. project/design 이름, 변수값, body 이름, bbox, volume을 manifest로 추출한다.
3. 좌표축과 core/TX/RX 방향을 캡처한다.
4. 그 결과를 `reference_id` 하나로 동결한다.

완료 조건: “어떤 파일의 어떤 design과 어떤 변수점이 정답인가?”에 경로 하나로 답할 수 있음.

### Phase 1 — fixed TOML + core

1. `evdd/spec.py`와 fixed TOML을 만든다.
2. EI 또는 선택 family의 core만 생성한다.
3. core bbox/volume/gap을 gold와 비교한다.

완료 조건: core 단독 STEP이 수치 기준을 통과함.

### Phase 2 — primary winding

1. centerline 생성 규칙을 수치 좌표로 옮긴다.
2. planar 또는 litz-equivalent 단면 sweep를 구현한다.
3. layer mirror/offset/connector/union을 구현한다.
4. primary bbox, volume, terminal 좌표를 비교한다.

### Phase 3 — secondary winding + full scene

1. `Rx_1`, `Rx_2` path와 Z placement를 구현한다.
2. core/TX/RX body assembly를 만든다.
3. STEP + ledger + resolved TOML을 export한다.
4. STEP 재수입과 full-scene metrics 비교를 통과시킨다.

### Phase 4 — family 확장

한 family가 완전히 통과한 뒤에만 다음 순서로 확장한다.

1. `EI_pl_pl`
2. `primary_4turn`
3. `sec2turn`
4. `EE_pl_pl`
5. `litz_plate`
6. legacy `v1/v2/v3`
7. 마지막으로 `super` 파일별 provenance 정리

family별 builder를 복사하지 말고 core topology, conductor topology, turn/layout policy를 조합하되,
지원하지 않는 조합은 fallback 없이 raise한다.

### Phase 5 — sweep는 별도 작업

fixed-point CAD가 gold 비교를 통과한 뒤에만 sweep TOML과 sampler를 추가한다.

- 각 독립 자유도는 canonical owner 하나만 가짐
- explicit seed 필수
- sampler는 fixed TOML을 생성
- CAD builder는 fixed TOML만 소비
- 같은 fixed TOML은 seed와 무관하게 같은 geometry를 생성해야 함
