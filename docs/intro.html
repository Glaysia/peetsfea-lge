peetsfea · v0.3.8.0

TOML 명세에서 HFSS 설계를
결정적으로 생성합니다.

peetsfea는 선언적 TOML 입력으로부터 최소 STEP 형상과 2-포트 HFSS(AEDT) 프로젝트를 재현 가능하게 빌드하는 Python 파이프라인입니다. headless EM setup · solve · report까지 하나의 결정적 경로로 이어집니다.

빠른 시작 → 파이프라인 보기

무엇을 하나요

정확히 하나의 활성 계약만 유지하는 미니멀 기준선(baseline).

📐

선언적 TOML 입력

authoring 표면은 [design]과 [[non_model_objects]]만 허용합니다. legacy modeled-object 섹션은 파서가 거부합니다.

🧩

최소 STEP 형상

authored non-model box와 고정된 Tx/Rx 포트 셀을 STEP solid로 내보내고 ledger에 기록합니다.

⚡

Headless EM 경로

STEP를 headless HFSS로 import하여 mesh · boundary · ports · setup · report 상태를 결정적으로 할당합니다.

🔁

재현 가능한 산출물

source / repro / dataset 스냅샷과 ledger를 남겨 동일 입력이 동일 결과를 만들도록 보장합니다.

🌀

SSW 코일 디버그

[constraints] 표면으로 SSW 코일·under-coil·MULL ferrite 배치를 탐색하는 별도 디버그 입력을 제공합니다.

🛑

Fail-Fast 계약

PyAEDT의 False 반환은 즉시 raise합니다. nullable·fallback·degraded 경로를 두지 않습니다.

런타임 파이프라인

TOML 한 장에서 풀이된 .aedt와 CSV 리포트까지.

  1. sample — entry/sample.py가 source TOML을 복사하고 source/repro/dataset 스냅샷을 쓰며, minimal_scene.step과 minimal_step_ledger.json을 내보냅니다.
  2. build — entry/build.py가 manifest를 읽어 누락된 STEP를 재생성하고, headless HFSS로 import한 뒤 mesh/boundary/ports/sources/setup/report를 할당·검증하고 .aedt를 저장합니다.
  3. solve — build.py --solve가 Setup1을 실행하고 Output Variables Table1을 CSV로 export한 뒤 프로젝트를 다시 저장합니다.

현재 계약 v0.3.8.0

0.3.x 기준선이 활성으로 유지하는 표면.

  • 활성 입력: examples/minimal_step_two_port.toml
  • TOML surface: [design] · [[non_model_objects]] 만 허용
  • STEP surface: authored non-model box + 고정 Tx/Rx port cell (각 셀 = signal pad · reference pad · vacuum port sheet)
  • EM surface: Tx 포트 1 · Rx 포트 1 · copper pad mesh · radiation boundary · Setup1 · Sweep · Output Variables Table1
  • Ports/Sources: 터미널 1_T1 / 2_T1 고정, Tx 1V@0° · Rx 0V@0°
  • Sweep: 0.1MHz → 100MHz log 401 포인트 interpolating + DC subrange, 6.78MHz solve
  • SSW 제약: enabled 코일은 gcd(turn_n_int, twist_factor) == 1, RX enabled 시 turn_n_int > 1, TX/RX void_profile은 scaled profile 1로 고정

빠른 시작

모든 명령은 run/에서 실행합니다.

테스트 & 타입 검사

cd run
../.venv/bin/pytest -q ../tests
../.venv/bin/pyright ../src ../entry ../tests

최소 STEP 샘플 생성

cd run
../.venv/bin/python ../entry/sample.py

Setup-ready AEDT 프로젝트 빌드 & solve

cd run
../.venv/bin/python ../entry/build.py            # setup-ready .aedt 생성
../.venv/bin/python ../entry/build.py --solve    # solve + CSV report export
주의 · python -O는 지원하지 않습니다 (assertion이 런타임 계약의 일부). AEDT/PyAEDT에 영향을 주는 변경은 반드시 실제 headless AEDT 검증을 통과해야 합니다.
