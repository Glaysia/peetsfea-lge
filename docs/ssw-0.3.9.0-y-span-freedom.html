SSW Y 길이 자유도 3배 확대 — 0.3.9.0

TX/RX SSW 코일의 글로벌 Y축 길이 상한을 3배로 키워, 길쭉한(elongated) 형상까지 설계공간에 넣었다. Y 길이는 width_max_mm × width_ratio로 정의되므로 상한(width_max_mm)을 3배로 올리면 같은 ratio에서 형상이 3배 길어진다. 설계공간이 바뀌었으므로 spec_version을 0.3.9.0으로 올린다.

1. 무엇을 바꿨나 0.3.9.0

Y축을 지배하는 width_max_mm를 360 → 1080 (3×)으로 올리고, 코일이 들어갈 배치 한계 박스(*_region_max)의 Y 크기도 같이 3배로 키웠다.

두 TOML 모두 적용: 0.3.x_sweep.toml(설계공간 SSOT) + 0.3.x_fixed.toml(고정점 예제). height_max_mm(=TX의 X / RX의 Z)는 그대로 둔다 — 이번 변경은 Y축 한정.

2. 왜 Y = width_max_mm 인가

경험적으로 body bounding box를 찍어보면, TX·RX 두 형상 모두 글로벌 Y축 길이 ≈ width_mm = width_max_mm × width_ratio 였다.

축 대응 (배치 후)
  • TX (XY 평면, thin-Z): Y ← width, X ← height
  • RX (YZ 평면, thin-X): Y ← width, Z ← height
  • 즉 두 코일 모두 Y = width 계열 → 공유 필드 width_max_mm 하나로 둘 다 늘어남.
3배 검증 (fixed 예제)
  • TX copper Y: 166.5 → 497.2 mm (≈3×)
  • RX copper Y: 356.4 → 1068.8 mm (≈3×)
  • ratio 고정 시 상한 3배 → 형상 3배. 선형 관계 확인.

3. region_max도 같이 키워야 했던 이유 ValueError

width_max만 올리면 코일은 길어지지만, 배치 한계 박스가 그대로라 placement 검증에서 막힌다.

ValueError: RX SSW Y span does not fit inside rx_region_max (span=1068.83564, rx_region_max_y_size=480.14)
  • *_region_max는 코일이 들어갈 수 있는 최대 박스(non-model object)다. 이게 곧 "max"의 실체.
  • 상위 박스 tv/tx_region은 Y=1842라 1440.42를 이미 충분히 담으므로 그대로 둔다.
  • 헤드룸: 코일 Y 최대 ≈ 1080(+trace) < region_max Y 1440.42 → 여유 확보.

4. 버전 정책 — 이번엔 spec까지 올림

0.3.8.1~0.3.8.3은 솔버 설정(패스·메시)만 바꾼 패키지 패치라 spec_version은 0.3.8.0 고정이었다. 0.3.9.0은 설계공간(geometry SSOT)이 바뀌었으므로 spec까지 올린다.
